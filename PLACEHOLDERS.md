# Placeholdery PlaceholderAPI — GrzybcioRynek

Wymaga zainstalowanego **PlaceholderAPI**. Bez niego plugin działa normalnie, a placeholdery są niedostępne.

Identyfikator ekspansji: `grybciorynek`

## Lista

| Placeholder | Opis |
|-------------|------|
| `%grybciorynek_active_listings%` | Liczba aktywnych ofert na rynku |
| `%grybciorynek_player_listings%` | Liczba aktywnych ofert gracza |
| `%grybciorynek_total_sales%` | Liczba zakończonych sprzedaży gracza |
| `%grybciorynek_total_spent%` | Suma wydana przez gracza (sformatowana) |
| `%grybciorynek_total_earned%` | Suma zarobiona przez gracza netto (sformatowana) |
| `%grybciorynek_market_volume%` | Całkowity obrót rynku (sformatowany) |
| `%grybciorynek_mailbox_count%` | Liczba itemów w skrzynce gracza |
| `%grybciorynek_rating%` | Średnia ocena sprzedawcy (1 miejsce po przecinku) |

## Przykład

```text
Oferty: %grybciorynek_player_listings%
Obrót serwera: %grybciorynek_market_volume%
```
